# 📈 Enhancing Supermarket Inventory Management Through ARIMA and SARIMAX-Based Demand Forecasting

## 🧾 Abstract

This project focuses on **supermarket demand forecasting** using time-series analysis techniques, specifically **AutoRegressive Integrated Moving Average (ARIMA)** and **Seasonal AutoRegressive Integrated Moving Average with Exogenous Variables (SARIMAX)**.

The project uses supermarket sales data from **2015 to 2018** to analyze historical demand patterns and forecast future demand. Accurate demand forecasting can help retailers make better inventory decisions, optimize stock levels, and reduce the risks associated with **overstocking and stockouts**.

The dataset is preprocessed and transformed into a suitable time-series format before being divided into **training and testing datasets**. ARIMA and SARIMAX models are developed and evaluated by comparing their forecasts with the actual values from the test period.

The SARIMAX model additionally considers **seasonal patterns and exogenous variables**, allowing more complex demand patterns to be captured.

## 📈 Forecasting Models

### 🔹 ARIMA

**AutoRegressive Integrated Moving Average (ARIMA)** is a time-series forecasting model used to capture trends and autocorrelation within historical demand data.

ARIMA incorporates:

* **AutoRegressive (AR)** component
* **Integrated (I)** component
* **Moving Average (MA)** component

The model is used to forecast supermarket demand based on historical observations.

### 🔹 SARIMAX

**Seasonal AutoRegressive Integrated Moving Average with Exogenous Variables (SARIMAX)** extends the ARIMA approach by incorporating:

* **Seasonality**
* **Autoregressive components**
* **Moving-average components**
* **Differencing**
* **Exogenous variables**

SARIMAX is used to capture more complex demand patterns influenced by seasonal trends and external factors.

## 📉 Evaluation Metrics

The forecasting models are evaluated by comparing their predicted values with the actual values from the testing dataset.

### 📌 Mean Absolute Error (MAE)

**Mean Absolute Error (MAE)** measures the average absolute difference between the actual and predicted values.

A lower MAE indicates that the predictions are closer to the actual values.

### 📌 Mean Squared Error (MSE)

**Mean Squared Error (MSE)** measures the average squared difference between actual and predicted values.

A lower MSE indicates better forecasting performance.

### 📌 Mean Absolute Percentage Error (MAPE)

**Mean Absolute Percentage Error (MAPE)** measures the average percentage difference between actual and predicted values.

A lower MAPE indicates better forecasting accuracy.

### 📌 Time-Series Cross-Validation

**Time-series cross-validation** evaluates model performance while maintaining the chronological order of observations.

This prevents future observations from being used to predict past observations.
